# 360 Signs & VM — Refreshed

A complete static website, ready for GitHub Pages. No installation, build step or API key is needed.

## Publish it from GitHub

1. Extract this ZIP on your computer.
2. On GitHub, create a new public repository, for example `360-signs-preview`.
3. Choose **Add file → Upload files**. Upload the contents of the extracted folder, including the `assets` folder. `index.html` must sit at the top level of the repository, not inside another folder. Do not upload the ZIP itself.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**, then **main** and **/ (root)**. Click **Save**.
7. Wait for the deployment to finish. GitHub displays your website link in the Pages settings. It normally has the form `https://YOUR-USERNAME.github.io/360-signs-preview/`.
8. Send that website link to your colleague. They will not need a ChatGPT account.

GitHub Pages publishes the site publicly. Use this as a preview for review; it does not change the live 360 Signs company website.

## Preview without publishing

Open `index.html` in your browser. You can also send this ZIP to a colleague and ask them to extract it and open `index.html`.

## Included

- Responsive desktop and mobile layouts.
- Eight client logos with drag, swipe and bar controls, plus automatic scrolling after four seconds of inactivity.
- Eight projects with search, sector and service filters.
- Photo galleries, thumbnails and related projects.
- Reduced-motion support and keyboard controls.
- Direct email and phone links using the current 360 contact details.

## Editing

- `index.html`: page content and project cards.
- `style.css`: layout, colours and styling.
- `projects.js`: project details and gallery photographs.
- `script.js`: filters, galleries and brand scrolling.
- `assets/`: photographs and brand logos.

All paths are relative so the site works under a GitHub repository URL. Keep the folder structure intact. Photography and brand assets retain their original ownership; no additional rights are granted by this package.
